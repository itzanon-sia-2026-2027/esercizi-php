Lezione 7c - Statistiche del Catalogo

Obiettivo: Creare una pagina di reportistica (statistiche.php) che mostri un riepilogo quantitativo della biblioteca. Sfrutteremo le funzioni aggregate di SQL (COUNT, AVG) associate alla clausola GROUP BY, visualizzando i dati in tabelle HTML strutturate.

1. Logica di Estrazione Dati (PHP)

Crea un nuovo file chiamato statistiche.php. Nella parte superiore del file, subito dopo aver incluso la connessione al database, eseguiamo due distinte query di raggruppamento.

<?php
require_once 'connessione.php';

// 1. QUERY: Conteggio dei libri suddivisi per ogni categoria
$sql_categorie = "SELECT categorie.nome AS categoria, COUNT(libri.id) AS totale_libri
                  FROM categorie
                  LEFT JOIN libri ON categorie.id = libri.categoria_id
                  GROUP BY categorie.id, categorie.nome
                  ORDER BY totale_libri DESC, categorie.nome";
$stmt_cat = $pdo->prepare($sql_categorie);
$stmt_cat->execute();
$stat_categorie = $stmt_cat->fetchAll();

// 2. QUERY: Calcolo della media degli autori per libro, raggruppati per categoria
// Usiamo una sottoquery o una JOIN complessa per contare gli autori per ciascun libro prima di farne la media
$sql_media_autori = "SELECT categorie.nome AS categoria, 
                            ROUND(AVG(conteggio_autori.num_autori), 1) AS media_autori
                     FROM categorie
                     INNER JOIN libri ON categorie.id = libri.categoria_id
                     INNER JOIN (
                         SELECT libro_id, COUNT(autore_id) AS num_autori 
                         FROM libro_autore 
                         GROUP BY libro_id
                     ) AS conteggio_autori ON libri.id = conteggio_autori.libro_id
                     GROUP BY categorie.id, categorie.nome
                     ORDER BY media_autori DESC";
$stmt_autori = $pdo->prepare($sql_media_autori);
$stmt_autori->execute();
$stat_autori = $stmt_autori->fetchAll();
?>

Nella prima query utilizziamo una LEFT JOIN: in questo modo, se una categoria nel database non contiene ancora nessun libro, verrà comunque inclusa nel report mostrando il valore 0 invece di essere nascosta.

Nella seconda query integriamo la funzione AVG() per calcolare la media aritmetica e la nidifichiamo dentro ROUND(..., 1) per limitare l'output a una sola cifra decimale, evitando la stampa a schermo di numeri con troppi decimali (es. 1.3333333).

2. Visualizzazione dei Dati (HTML/PHP)

Sotto al blocco PHP, implementa la struttura della pagina usando tabelle HTML semantiche per mostrare i due report separatamente.

<!DOCTYPE html>
<html lang="it">
<head>
    <meta charset="UTF-8">
    <title>Statistiche Biblioteca</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <header>
        <h1>📊 Statistiche del Catalogo</h1>
        <p><a href="index.php">🏠 Torna alla Ricerca</a></p>
    </header>

    <main class="statistiche-container">
        <section>
            <h2>Libri per Categoria</h2>
            <table class="tabella-stat&">
                <thead>
                    <tr>
                        <th>Categoria</th>
                        <th>Numero di Libri</th>
                    </tr>
                </thead>
                <tbody>
                    <?php foreach ($stat_categorie as $cat) { ?>
                        <tr>
                            <td><?= htmlspecialchars($cat['categoria']) ?></td>
                            <td><strong><?= $cat['totale_libri'] ?></strong></td>
                        </tr>
                    <?php } ?>
                </tbody>
            </table>
        </section>

        <section>
            <h2>Media Autori per Libro per Categoria</h2>
            <table class="tabella-stat&">
                <thead>
                    <tr>
                        <th>Categoria</th>
                        <th>Media Autori</th>
                    </tr>
                </thead>
                <tbody>
                    <?php foreach ($stat_autori as $aut) { ?>
                        <tr>
                            <td><?= htmlspecialchars($aut['categoria']) ?></td>
                            <td><?= $aut['media_autori'] ?> autori/libro</td>
                        </tr>
                    <?php } ?>
                </tbody>
            </table>
        </section>
    </main>

    <footer>
        <p>&copy; 2026 5B SIA</p>
    </footer>
</body>
</html>

Verifica

  • Crea il file statistiche.php e aprilo nel browser.
  • Verifica che l'ordinamento della prima tabella mostri in cima le categorie con più libri inseriti (ordinamento discendente).
  • Assicurati che i valori decimali delle medie siano formattati correttamente con un solo punto decimale grazie alla funzione ROUND.
  • Aggiungi un nuovo libro dal pannello di gestione associandolo a una categoria poco popolata e ricarica la pagina per osservare l'aggiornamento automatico dei calcoli in tempo reale.
