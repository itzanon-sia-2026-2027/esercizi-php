Lezione 7c - Statistiche del Catalogo

Obiettivo: Creare una pagina di reportistica (statistiche.php) che mostri un riepilogo quantitativo della biblioteca. Sfrutteremo le funzioni aggregate di SQL (COUNT, AVG) associate alla clausola GROUP BY, visualizzando i dati in tabelle HTML strutturate.

1. Logica di Estrazione Dati (PHP)

Crea un nuovo file chiamato statistiche.php. Nella parte superiore del file, subito dopo aver incluso la connessione al database, eseguiamo due distinte query di raggruppamento.

Nella prima query utilizziamo una LEFT JOIN: in questo modo, se una categoria nel database non contiene ancora nessun libro, verrà comunque inclusa nel report mostrando il valore 0 invece di essere nascosta.

Nella seconda query integriamo la funzione AVG() per calcolare la media aritmetica e la nidifichiamo dentro ROUND(..., 1) per limitare l'output a una sola cifra decimale, evitando la stampa a schermo di numeri con troppi decimali (es. 1.3333333).

2. Visualizzazione dei Dati (HTML/PHP)

Sotto al blocco PHP, implementa la struttura della pagina usando tabelle HTML semantiche per mostrare i due report separatamente.

Verifica

  • Crea il file statistiche.php e aprilo nel browser.
  • Verifica che l'ordinamento della prima tabella mostri in cima le categorie con più libri inseriti (ordinamento discendente).
  • Assicurati che i valori decimali delle medie siano formattati correttamente con un solo punto decimale grazie alla funzione ROUND.
  • Aggiungi un nuovo libro dal pannello di gestione associandolo a una categoria poco popolata e ricarica la pagina per osservare l'aggiornamento automatico dei calcoli in tempo reale.
