Lezione 7b - Cercare nel catalogo

Obiettivo: con molti libri non è pratico caricare tutto il catalogo. Modifica index.php: chiedi una parte del titolo e mostra al massimo 20 risultati, senza JavaScript.

1. Leggere i criteri e cercare

Sostituisci la query iniziale della lezione 7 con questo codice, dopo require_once 'connessione.php';. La query parte solo se il titolo è stato inserito; controlliamo i dati anche sul server, non solo nel form. Prima contiamo i risultati totali, poi preleviamo al massimo i primi 20.

$titolo = $_GET['titolo'] ?? '';
$errore = '';
$libri = [];
$totale_risultati = 0;
$altri_risultati = false;

if (!is_string($titolo)) {
    $titolo = '';
    $errore = 'Inserisci un titolo valido.';
} else {
    $titolo = trim($titolo);
    if (!empty($titolo)) {
        // 1. CONTEGGIO DEI RISULTATI TOTALI
        $sql_count = "SELECT COUNT(*) AS totale FROM libri WHERE titolo LIKE ?";
        $stmt_count = $pdo->prepare($sql_count);
        $stmt_count->execute(['%' . $titolo . '%']);

        $riga_count = $stmt_count->fetch();
        $totale_risultati = $riga_count['totale'];
        $altri_risultati = ($totale_risultati > 20);

        // 2. RECUPERO DEI SOLI 20 RECORD DA MOSTRARE
        $sql = "SELECT libri.id, libri.titolo, libri.anno_pubblicazione,
                       categorie.nome AS categoria
                FROM libri
                INNER JOIN categorie ON libri.categoria_id = categorie.id
                WHERE libri.titolo LIKE ?
                ORDER BY libri.titolo, libri.id
                LIMIT 20";
        $stmt = $pdo->prepare($sql);
        $stmt->execute(['%' . $titolo . '%']);
        $libri = $stmt->fetchAll();
    }
}

empty verifica anche se la variabile è definita e considera vuota la stringa '0'. Il controllo is_string evita errori se viene inviato un array al posto del titolo. LIKE cerca il testo anche all'interno del titolo; % e _ inseriti nella ricerca restano caratteri speciali di LIKE, non vengono cercati letteralmente.

La prima query con COUNT(*) calcola il numero totale senza scaricare tutti i libri in memoria PHP; la seconda ne recupera al massimo 20. L'ordinamento per titolo e ID è stabile anche quando più libri hanno lo stesso titolo. Se più di 20 libri hanno esattamente lo stesso titolo, precisare il titolo non basta a mostrarli tutti: è un limite di questa versione semplice.

2. Form e risultati

Tra l'header e il main aggiungi il form e il blocco di messaggi condizionali. Mantieni dentro main il ciclo delle schede della lezione 7: ora riceve al massimo 20 libri.

<form class="catalogo-ricerca" action="index.php" method="get">
    <label for="titolo">Cerca nel titolo</label>
    <input id="titolo" name="titolo" type="search" required
           value="<?= htmlspecialchars($titolo) ?>">
    <button type="submit">Cerca</button>
</form>
<?php if ($errore !== '') { ?>
    <p class="catalogo-messaggio" role="alert"><?= htmlspecialchars($errore) ?></p>
<?php } elseif (empty($titolo)) { ?>
    <p class="catalogo-messaggio">Inserisci una parte del titolo per cercare.</p>
<?php } elseif (count($libri) === 0) { ?>
    <p class="catalogo-messaggio">Nessun libro trovato.</p>
<?php } elseif ($altri_risultati) { ?>
    <p class="catalogo-messaggio">Trovati <?= $totale_risultati ?> risultati. Sono mostrati solo i primi 20. Specifica meglio il titolo per affinare la ricerca.</p>
<?php } ?>

Il CSS in lavoro/css/style.css contiene già le regole per .catalogo-ricerca e .catalogo-messaggio. La query degli autori resta nel ciclo, ma viene eseguita per al massimo 20 libri alla volta.

Dentro ogni scheda del ciclo della lezione 7 aggiungi il link alla modifica del libro:

<a href="libri_edit.php?id=<?= $l['id'] ?>">Modifica libro</a>

Verifica

  • Apri la home: non deve mostrare libri prima della ricerca. Invia anche un titolo vuoto, composto da spazi o uguale a 0.
  • Cerca buon e poi un titolo inesistente. Prova anche % e _ e osserva che funzionano come caratteri speciali di LIKE.
  • Da un risultato apri la modifica del libro e segui il link a un autore collegato.
  • Cerca Viaggi immaginari: nei dati di esempio ci sono 24 libri inventati, quindi compare il numero esatto di corrispondenze e l'invito a precisare la ricerca. La pagina fetch della prossima lezione è separata e non eredita automaticamente questo limite.
