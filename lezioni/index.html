Lezioni: dal primo SELECT al portale gestionale

Si riparte da zero e si costruisce un portale gestionale per una biblioteca, un passo alla volta. La soluzione completa e i passi intermedi (passo-01 … passo-08) sono nel branch soluzione del repository: l'insegnante li renderà disponibili. Usali per confrontare il tuo lavoro, non per copiare.

Prima di iniziare

  1. Lavora nella cartella lavoro/: contiene già connessione.php e lo stile in css/. Tutti i file che crei vanno qui dentro.
  2. Il database database/biblioteca.sqlite si crea da solo, con i dati di esempio (guarda database/schema_sqlite.sql). Per ricominciare cancella il file .sqlite.
  3. Avvia il server con il task "4. Avvia Server PHP (file corrente)" del profilo VSCode.

Lo schema del database:

categorie (id, nome)                      1 ──< N   libri (id, titolo, anno_pubblicazione, categoria_id)
libri  >──< autori (id, nome, cognome)    N:M tramite libro_autore (libro_id, autore_id, ruolo)

Convenzioni (le stesse usate in classe)

  • Ogni pagina inizia con require_once 'connessione.php'; e usa la variabile $pdo.
  • Un file per ogni operazione: categorie.php, categorie_insert.php, categorie_delete.php, categorie_edit.php, categorie_update.php.
  • Le query con dati dell'utente usano sempre prepare con i segnaposto ? e execute([ ... ]):
$stmt = $pdo->prepare("UPDATE autori SET nome = ?, cognome = ? WHERE id = ?");
$stmt->execute([$nome, $cognome, $id]);

I valori nell'array vanno nello stesso ordine dei ?. Non si usano i parametri con nome. - Dopo una scrittura: header("Location: pagina.php"); exit;. - Ogni dato mostrato in pagina passa da htmlspecialchars().

Sequenza

# Lezione Argomento
1 Leggere i dati connessione, query, fetchAll, tabella HTML
2 Inserire e cancellare form, prepare/execute, redirect
3 Modificare fetch, <input type="hidden">, UPDATE
4 Messaggi ed errori sessione, try/catch, chiavi esterne
5 Seconda tabella: libri INNER JOIN, menu a tendina
6 Relazione N:M: autori dei libri tabella ponte, padre-figlio
7 Il catalogo pubblico pagina finale, cicli annidati, home del portale
8 Ultima lezione: fetch JavaScript che chiede a PHP pezzi di HTML

Alla fine della lezione 7 hai un portale completo. Cambiando tabelle e campi puoi costruire lo stesso portale per qualsiasi altro tema (negozio, palestra, scuola...).
