Per iniziare:
In laboratorio le postazioni sono già predisposte. 
Estrai lo ZIP in una cartella a tua scelta e clicca sulla stella nella barra laterale di VS Code. 
Scegli Importa DB da file .sql e seleziona schema.sql.

Per testare la connessione al DB, apri il file lavoro/index.php, clicca di nuovo sulla stella e scegli Avvia Server PHP.
Crea i file PHP dentro la sottocartella 'lavoro'. 
Per provare l’esercizio, clicca di nuovo sulla stella e scegli Avvia Server PHP.

Segui la lezione assegnata. Se lavori da casa, consulta anche la guida setup (link su classroom).
